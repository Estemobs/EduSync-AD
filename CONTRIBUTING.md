# Contribution

Merci de vouloir contribuer à EduSync AD !

## Développement

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
python src/edusync_ad/app.py
```

## Vérifications avant PR

```bash
pytest
```

## Pull requests

1. Décrivez le problème résolu et testez en mode simulation.
2. Gardez la PR petite et ciblée.
3. Référencez l'issue concernée dans la description.
